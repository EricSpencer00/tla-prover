A warehouse robot fleet limits how many robots may be simultaneously active in a shared charging zone, coordinated by two dispatchers that share the pool through a compare-and-swap register holding the active count. A dispatcher reads a snapshot of the active count, then attempts to admit one robot: the compare-and-swap succeeds only if the snapshot still equals the live count and the count is below the zone capacity, atomically incrementing the count. If another dispatcher changed the count in between, the snapshot is stale and the dispatcher aborts and re-reads. An active robot may leave, decrementing the count. The model tracks the active count and each dispatcher's read snapshot.
SAFETY PROPERTY: the number of active robots in the zone never exceeds the zone capacity.
