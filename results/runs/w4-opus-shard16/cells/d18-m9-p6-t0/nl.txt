A smart-home door-lock network is coordinated by a hub that stamps the whole network with an epoch number. Whenever the hub reconfigures the network, for example after a lock is added or a key is rotated, it advances to a new epoch, which retires the previous one. Each door lock remembers the epoch it last learned; a lock may catch up by adopting the hub's current epoch. A lock may carry out a privileged action on the shared front-bolt only while the epoch it knows matches the hub's current epoch; carrying out an action records which lock acted and the epoch it acted under, and marks that an action has occurred in the current epoch. When the hub reconfigures to a new epoch, it clears the record that an action has occurred, since no lock has yet acted under the new epoch. A lock can crash silently at any time, after which it takes no actions until it later recovers. The danger the epoch stamp defends against is a stale lock, one still holding a retired epoch, carrying out an action on the bolt as though it were current.
SAFETY PROPERTY: Whenever an action has been recorded under the current epoch, the epoch that action was carried out under equals the hub's current epoch, so no stale lock ever acts.
