A smart-home system is driven by two independent automation instances that share one pool of room-setting records. To change a record safely the instances use two-level hierarchical locking: an instance must first take the house-wide coarse lock, and only while holding it may it take a room-level fine lock on the specific room it wants to change. Because the coarse lock has a single holder, the two instances can never both be inside the locking hierarchy at once. When an instance takes a room's fine lock it snapshots that room record's current version number. It may write the record only while holding that room's fine lock and only if its snapshot still matches the room's live version; a write advances the room's version by one and records the base version the write was built on. An instance releases the fine lock on a room and, once it holds no fine locks, releases the coarse lock so the other instance can proceed. This coarse-then-fine discipline serialises all writers so that no instance's update is ever silently overwritten by another operating on the same record.
SAFETY PROPERTY: For every room record, the latest committed write was built on the version immediately preceding the current one, so no update is ever lost.
